# آدمک‌ساز — فایل‌های آپدیت

این مخزن با GitHub Pages در `https://kakadoo91.github.io/adamak-saz/` منتشر می‌شود و اپ اندروید آدمک‌ساز آپدیت‌هایش را از این‌جا می‌گیرد.

- `update.json` — شماره‌ی نسخه‌ها. اپ هر بار که باز می‌شود این را می‌خواند.
  - `web`: نسخه‌ی فایل‌های داخل `www/`. اگر بالاتر باشد، اپ بی‌صدا دانلودشان می‌کند و دفعه‌ی بعد استفاده می‌کند.
  - `apk`: آخرین نسخه‌ی اپ. اگر بالاتر از نسخه‌ی گوشی باشد، پیشنهاد آپدیت نشان داده می‌شود.
  - `minApk`: گوشی‌هایی که پایین‌تر از این باشند **باید** آپدیت کنند (صفحه‌ی آپدیت اجباری).
- `www/` — خود برنامه.
- `AdamakSaz.apk` — آخرین فایل نصب.

کلید امضا و سورس اندروید عمداً این‌جا نیست (این مخزن عمومی است).
